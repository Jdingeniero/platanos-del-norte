# Sitio señuelo - Plátanos del Norte (práctica Google Dorks)

Sitio ESTÁTICO indexable para la Actividad 2 (Google Dorks). Empresa ficticia, datos inventados.

## Qué contiene
- Páginas públicas (objetivos de dork, con sus flags D1-D6) + 404.html
- robots.txt (con rutas Disallow y FLAG-01) y sitemap.xml
- documentos/ : PDF (FLAG-D4) y XLSX (FLAG-D5 en metadatos)

## IMPORTANTE antes de publicar
(Ya configurado para https://jdingeniero.github.io/platanos-del-norte/)
(p. ej. https://TU-USUARIO.github.io/NOMBRE-REPO  o  https://TUSITIO.netlify.app).

## Publicar en GitHub Pages
1. Crea un repositorio PÚBLICO y sube TODO el contenido de esta carpeta a la raíz.
2. Settings -> Pages -> Deploy from a branch -> rama main, carpeta / (root) -> Save.
3. En 1-2 min tendrás la URL. (Para que robots.txt/sitemap funcionen como raíz,
   usa un repo tipo usuario.github.io o un dominio propio.)

## Publicar en Netlify (más simple, dominio raíz)
1. netlify.com -> Sign up with GitHub.
2. "Add new site" -> "Deploy manually" -> arrastra esta carpeta.
3. Te da una URL xxx.netlify.app ya indexable.

## Después
- Da de alta la URL en Google Search Console, envía el sitemap y pide indexación.
